**Stay calm at 3 a.m.** On-Call is a four-week cohort for engineers who carry the pager, or are about to. You will learn to take command of an incident, coordinate responders, keep stakeholders informed and turn every outage into a better system. In week three you run a live game day: a simulated cascading failure in a sandbox cluster, graded on how you command it.

## Curriculum

| Module | Week | Formats |
|---|---|---|
| 0. Briefing | 1 | kickoff video, rules of engagement |
| 1. Signals | 1 | annotated dashboard, SLOs and error budgets, conference talk |
| 2. Command | 2 | SEV1 role-play video, bridge-call recording, branching scenario, printable runbook |
| 3. Game day | 3 | SCORM outage simulator, xAPI-tracked live drill, comms quiz |
| 4. After | 4 | blameless postmortems, postmortem assignment with peer and tutor review |

## Outcomes

- Declare and classify incidents with a shared severity matrix
- Run the first five minutes of a SEV1: roles, channel, first update
- Communicate impact, current action and next update time to any audience
- Alert on SLO burn rate instead of on causes
- Write a blameless postmortem with owned, dated action items

## Format

Four weeks, about 4–5 hours a week, plus a 90-minute live drill. Each cohort has at most 24 engineers, so every drill gets individual feedback. Deadlines are real: the comms quiz closes on Thursday of week 3, the postmortem is due at the end of week 4.
