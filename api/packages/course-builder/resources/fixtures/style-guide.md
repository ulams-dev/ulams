# Northwind Academy Style Guide

How we write for learners. An original, short guide used by the tests and the eval fixture.

## Voice

Write to the learner as "you". Keep a friendly but professional register: formality 3 of 5.
Keep sentences under 20 words. Prefer short paragraphs and concrete verbs.

## Reading level

English: grade 8. Polish: B1. Explain a new term the first time it appears.

## Terminology

- Use "learner", not "student" or "user".
- Write "Northwind Academy" with this exact casing, never "northwind academy" or "NWA".
- Use "lesson", not "unit" or "module page".

## Banned phrases

Never write "simply", "just" or "obviously". They make a step sound easier than it is.

## Components

Prefer Callout and WorkedExample for key ideas. Do not use FlipCards or Marquee.

## Images

Every image needs alt text. No text inside images. Decorative images are not allowed.

## Colours and fonts

Brand colour: #1D6F5C. Theme preset: coffee. Fonts: Source Serif and Inter.

## Examples

> You start with one small task. Then you build on it, one step at a time.

> Run the command and check the output. If it differs from the page, tell us.
