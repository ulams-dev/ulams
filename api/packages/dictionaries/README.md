# Dictionaries

## What does it do

This package is used for managing dictionaries and their expressions.

## Installing

- `composer require ulams/dictionaries`
- `php artisan migrate`

## Endpoints

The endpoints are defined in [![swagger](https://img.shields.io/badge/documentation-swagger-green)](https://ulams.github.io/Dictionaries/)

## Tests

Run `./vendor/bin/phpunit` to run tests.
