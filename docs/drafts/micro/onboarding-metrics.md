# Onboarding Metrics Definitions

## Time to First Course

**Definition:** The duration from the moment a new user signs up for the platform until they access their first course.

**Start Event:** User completes the sign-up process and is redirected to the dashboard.

**Stop Event:** User accesses any course page for the first time.

**Exclusions:** 
- Users who sign up but do not log in.
- Users who sign up and log in but do not access any courses.

**Target:** To be decided by the owner.

## Time to First Enrolment

**Definition:** The duration from the moment a new user signs up for the platform until they enrol in their first course.

**Start Event:** User completes the sign-up process and is redirected to the dashboard.

**Stop Event:** User successfully enrolls in any course.

**Exclusions:** 
- Users who sign up but do not log in.
- Users who sign up and log in but do not enroll in any courses.

**Target:** To be decided by the owner.

## Admin Task Times

**Definition:** The duration it takes for an admin to complete a specific task from start to finish.

**Start Event:** Admin begins the task.

**Stop Event:** Admin completes the task and saves any changes.

**Exclusions:** 
- Time spent on tasks not directly related to the task in question.
- Time spent on tasks initiated by the admin but not completed within the same session.

**Target:** To be decided by the owner.

## Privacy

No personal data should be included in the metric events to ensure user privacy.
