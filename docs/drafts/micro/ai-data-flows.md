# AI Data Flows

## What leaves your server

1. **User Interactions**: Data generated by users during interactions with the AI tutor, such as questions, answers, and feedback.
2. **Course Content**: Metadata and structured data from the Course Builder, including course outlines, lesson plans, and assessment questions.
3. **Remediation Requests**: Data related to student remediation efforts, including specific areas of difficulty and suggested interventions.
4. **Insights Improvement Proposals**: Data collected to improve AI-driven insights, such as user feedback on suggested improvements and performance metrics.

## What never leaves

1. **Customer Content**: Any proprietary or sensitive content provided by customers is stored locally and never sent to external servers.
2. **User Data**: Personal data of users, unless explicitly shared by the user with permission, is kept on the server and not transmitted externally.

## Per-feature Table

| Feature               | Data Sent                     | Minimisation                    | Provider Choice | Logged Cost |
|-----------------------|-------------------------------|---------------------------------|-----------------|-------------|
| **Course Builder**    | Course metadata, lesson plans | Remove sensitive information    | OpenAI, Anthropic | Yes         |
| **AI Tutor**          | User interactions, questions  | Anonymize user data             | OpenAI, Anthropic | Yes         |
| **Remediation**       | Student performance data      | Aggregate and anonymize data    | OpenAI, Anthropic | Yes         |
| **Insights Improvement Proposals** | User feedback, performance metrics | Aggregate and anonymize data | OpenAI, Anthropic | Yes         |

## No Training on Customer Content

AI models are trained on generic datasets and do not receive any customer-specific content for training purposes. All interactions are processed in real-time without any data being used for training.

## Switching AI Off

To switch AI off, administrators can disable the AI services through the configuration settings. This will prevent any AI-driven features from being used, and all interactions will be handled locally without any external AI processing.
