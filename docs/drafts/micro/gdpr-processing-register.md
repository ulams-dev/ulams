## How to Answer a Data-Subject Request

1. **Data Access Request**: Provide a copy of the data processed about the data subject, including any AI-generated content.
2. **Data Correction Request**: Correct any inaccurate data and provide a copy of the updated data.
3. **Data Deletion Request**: Delete the data processed about the data subject, unless retention is required by law.
4. **Data Portability Request**: Provide the data in a structured, commonly used, and machine-readable format.
5. **Objection Request**: Object to the processing of data based on legitimate interest or automated decision-making.

Please submit all data-subject requests to the ULAMS Operator at [contact email]. Requests will be processed within 30 days of receipt.
