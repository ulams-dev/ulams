# MCP Evaluation Tasks for LMS Agents

| Task Prompt | Expected Tool Names | Pass Criterion |
|-------------|---------------------|----------------|
| Enrol a learner | MCP Tool A | The tool successfully enrolls a learner in a course. |
| Show overdue compliance | MCP Tool B | The tool displays learners who are overdue for a compliance check. |
| Preview a course update | MCP Tool C | The tool allows an agent to preview updates to a course. |
| Assign a course to a learner | MCP Tool D | The tool assigns a specified course to a learner. |
| Generate a learner report | MCP Tool E | The tool generates a comprehensive report for a learner's progress. |
| Update learner information | MCP Tool F | The tool updates personal or contact information for a learner. |
| Create a new course | MCP Tool G | The tool allows an agent to create a new course with basic details. |
| Delete a course | MCP Tool H | The tool deletes a specified course, with confirmation. |
| Move a learner between courses | MCP Tool I | The tool moves a learner from one course to another. |
| Reset learner progress | MCP Tool J | The tool resets the progress of a learner in a course. |
| Send a notification to a learner | MCP Tool K | The tool sends a notification to a learner via the LMS. |
| View learner activity logs | MCP Tool L | The tool displays logs of a learner's activities within the LMS. |
| Set course prerequisites | MCP Tool M | The tool sets prerequisites for a course, ensuring learners complete certain courses before proceeding. |
| Update course content | MCP Tool N | The tool allows an agent to update the content of an existing course. |
| Monitor system performance | MCP Tool O | The tool provides insights into the performance of the LMS system. |
