# WCAG 2.2 AA Manual Accessibility Test Checklist

## Keyboard
- [ ] All functionality is operable through a keyboard interface (SC 2.1.1)
- [ ] Keyboard navigation is logical and intuitive (SC 2.4.3)
- [ ] Focus order follows the visual hierarchy (SC 2.4.3)

## Focus visible and not obscured
- [ ] Focus indicator is visible and not obscured by other content (SC 2.4.7)
- [ ] Focus indicator has sufficient contrast (SC 1.4.11)

## Target size
- [ ] Interactive elements have a sufficient size for pointer interaction (SC 2.5.5)

## Forms and errors
- [ ] All form fields have associated labels (SC 3.3.2)
- [ ] Error messages are clear and descriptive (SC 3.3.1)
- [ ] Error messages are associated with the form fields (SC 3.3.1)

## Contrast
- [ ] Text has sufficient contrast against its background (SC 1.4.3)
- [ ] Interactive elements have sufficient contrast (SC 1.4.11)

## Motion and media
- [ ] All animations and transitions are smooth and do not cause motion sickness (SC 2.3.1)
- [ ] All media elements have captions and transcripts (SC 1.2.8)

## Screen reader names
- [ ] All interactive elements have appropriate ARIA labels (SC 4.1.2)
- [ ] All non-interactive elements have appropriate ARIA labels (SC 4.1.2)

## Zoom and reflow
- [ ] The page is fully usable at 200% zoom (SC 1.4.4)
- [ ] The page does not break when the browser window is resized (SC 1.4.10)
