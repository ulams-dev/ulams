# Ulam course: fact sheet (research step M9a)

Appendix to `docs/plans/interactive-demos.md`, section 7.3. The starting sheet (R0) was compiled on
2026-10-09 and re-checked in M9a on the same day: every row was checked again against the source it
names, and a primary source was added where one could be reached. The course outline that uses
these facts is `docs/plans/interactive-demos-ulam-outline.md`.

**Status: waiting for the owner's review (#151).** M9b writes the lessons from this sheet using the
resolutions in section 0, unless the owner objects there.

How to read the tables:

- **Status ✅**: cleared. The fact may appear in text, cards and quizzes, worded as in the row.
- **Status ⚠**: cleared only with the "sources differ" wording given in the row. Never quiz the
  disputed part.
- **Status (2nd)**: seen only in a secondary source, or a source that could not be opened. It may
  appear in text only with the hedge given in the row, and never in a quiz.
- **Status ✗**: do not use.
- `"…"` marks a verbatim quote that was read on the cited page. Quotes are kept short. No other
  quotes may be used.
- Source numbers refer to the "Sources" list at the end. Numbers 1–27 keep their R0 meaning; 28
  and above are new in M9a. Pointer sources (Wikipedia) are never cited in lessons.
