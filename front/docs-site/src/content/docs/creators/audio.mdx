An audio topic (`Audio`) plays one uploaded sound file.

<Steps>

1. In the program, add a topic and choose **Audio**.
2. Click **Click to upload** and choose an **MP3** or **OGG** file (these are the formats the server
   accepts), or pick one from the file browser.
3. The upload saves the topic and shows a player so you can check the file. Set the title and the
   [common fields](/creators/lessons-and-topics/#fields-every-topic-has) and save.

</Steps>

Use the topic's **Description** (Open editor) for a transcript; the reference front shows it below the
player.

## Completion

The reference front does not complete an audio topic by itself: the learner presses
**Mark as complete**.
