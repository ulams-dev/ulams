This section is for course authors and tutors. It walks through the admin panel screens you use to
build a course and explains what each topic type does for the learner.

## The authoring workflow

1. **Create the course** in **Courses → List → Create new**: title, descriptions, dates, status and
   authors. See [Create a course](/creators/create-a-course/).
2. **Build the program**: lessons (which can be nested) and topics inside them. Each topic has one
   type: text, video, H5P, quiz and so on. See [Lessons and topics](/creators/lessons-and-topics/).
3. **Prepare reusable content** where a topic needs it: H5P content, SCORM packages and LiaScript
   courses live in their own libraries under **Courses** and are picked from the topic form.
4. **Decide who gets in**: grant access to users and groups, handle access requests, attach a price,
   or make the course public. See [Access, prices and publishing](/creators/access-and-publishing/).
5. **Add a certificate** that is issued when a learner finishes the course. See
   [Certificates](/creators/certificates/).
6. **Publish** by setting the status to Published.

## Where things are in the admin panel

All authoring screens are under the **Courses** menu:

| Menu item | Path | What it is for |
|---|---|---|
| List | `/courses/list` | Course list, create, import, export, clone; opens the course editor |
| H5Ps | `/courses/h5ps` | H5P content library: create, edit, upload, export ([H5P](/creators/h5p/)) |
| LiaScript | `/courses/liascript` | LiaScript courses with versions ([LiaScript](/creators/liascript/)) |
| SCORMs | `/courses/scorms` | SCORM package library ([SCORM](/creators/scorm/)) |
| Categories | `/courses/categories` | Course categories (administrators) |
| Webinars | `/courses/webinars/list` | Live sessions (not covered here) |
| Access Requests | `/courses/access` | Learners' requests to join a course ([Access](/creators/access-and-publishing/)) |
| Quiz Reports | `/courses/quiz-reports` | Quiz attempts and manual grading ([Quizzes](/creators/quizzes/)) |

External tools for the [external tool topic](/creators/external-tool/) are registered by an
administrator under **Integrations → LTI** (see [LTI](/admin/lti/)), and certificate templates under
**Configuration → Templates** (see [Templates](/admin/templates/)).

<Aside>
Which menu items and tabs you see depends on your role's permissions and on a few global settings
(for example, a topic type can be switched off for the whole platform). If something described here is
missing, ask an administrator. The address `/courses/<anything>` (for example `/courses/list`) shows the
same course list.
</Aside>
