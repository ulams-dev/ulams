A PDF topic (`PDF`) shows one uploaded PDF document inside the lesson.

<Steps>

1. In the program, add a topic and choose **PDF**.
2. Click **Click to upload** and choose a `.pdf` file (only PDF is accepted).
3. The upload saves the topic and shows a preview with page navigation, so you can check the file.
4. Set the title and the [common fields](/creators/lessons-and-topics/#fields-every-topic-has) and save.

</Steps>

To offer a file for download next to other content instead, attach it to any topic under
**File resources** (see [Lessons and topics](/creators/lessons-and-topics/#fields-every-topic-has)).

## Completion

A PDF topic completes when the learner reaches the end of the page, or with **Mark as complete**.
