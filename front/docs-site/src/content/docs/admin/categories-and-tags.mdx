Two ways to classify content exist side by side:

- **Categories** are a managed tree. An administrator creates them on one screen, and other
  forms only pick from the tree. Package [categories](/reference/packages/categories/).
- **Tags** are free text typed directly on a course, webinar or product. There is no screen
  to manage them. Package [tags](/reference/packages/tags/).

## Categories

**Courses → Categories** (`/courses/categories`) needs the `category_list` permission and is
hidden when the `hideInMenu-CoursesCategories` setting is on. Creating, editing and deleting
need `category_create`, `category_update` and `category_delete`.

<Screenshot name="admin-courses-categories" alt="The category list with filters and the Show tree button" />

The table shows ID, name, the full name with its parents, the slug, **Active** and the parent
category, with filters by name and status. **Show tree** displays the whole hierarchy.

### Creating a category

<Steps>

1. Click **New**.
2. Enter the **Name**. The **Slug** is generated by the API from the name and cannot be
   edited.
3. Optionally add a **Description** and an **Order** (the sort position among siblings).
4. Turn on **Active**. Inactive categories are kept but frontends do not offer them.
5. Pick a **Parent category** to make it a subcategory, or leave it empty for a top-level
   category.
6. Click **OK**.
7. To add an **icon**, edit the category again: the upload only works for a saved category.
   The file goes to the `categories/{id}` folder of the [file library](/admin/files/).

</Steps>

A category cannot be deleted while it has subcategories or is used by a course; the API
returns an error.

### Where categories are used

- Courses, webinars, consultations and stationary events select categories in their forms
  ([Content creators](/creators/), [Webinars](/admin/webinars/)).
- A user's **Categories** tab stores the user's interests, for example a tutor's field
  ([Users](/admin/users/#categories-categories)).
- Dictionary words can be assigned to categories ([Dictionaries](/admin/dictionaries/)).
- The public endpoints `GET /api/categories` and `GET /api/categories/tree` let frontends
  build filters.

## Tags

Course, webinar and product forms have a **Tags** field. Type a word or phrase and press
**Enter** to add it; the field suggests tags already used anywhere on the platform
(`GET /api/tags/unique`). Tags are saved with the item, so a tag exists for as long as some
item uses it.

The public endpoints `GET /api/tags` and `GET /api/tags/unique` let frontends list items by
tag. Creating and deleting tags through the admin API needs `tags_create` and `tags_delete`.
