ulams is an open, headless LMS: a multi-tenant Laravel REST API with separate frontends for
learners and administrators. It started as a fork of Wellms (EscolaLMS) and lives in one
monorepo at [github.com/ulams-dev/ulams](https://github.com/ulams-dev/ulams).
