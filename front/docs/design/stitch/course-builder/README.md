# Course Builder and Phase 1 designs (Stitch)

Exports from the Stitch project **"ulams Course Builder"** (`4264779900987202361`), generated on
2026-10-08. These are platform-brand screens (the ulams product itself), not tenant themes; the tenant
experiences live in [`../screens`](../screens).

Each folder holds the exported HTML (`code.html`) and Stitch's 1440 px-wide screenshot
(`screen.webp`, lossy WebP `cwebp -q 72 -m 6`). The HTML is reference material only: it loads Tailwind
from a CDN and is not part of the app. Implementations use `@ulams/ui` components on `--ulams-*`
variables (ADR 0004, ADR 0008).

## Visual direction

Design system "Editorial Intelligence" (`assets/f711dc67c76f4846a76c762f05e0ff6e`), generated by Stitch
from the first prompt:

- Warm paper canvas `#F7F5F0`, white raised surfaces, hairline borders `#E6E2D9`, deep ink `#0E1220`
  for text and the left app rail.
- One action accent, electric iris `#5B5BF7` (primary buttons, focus rings, the glow around anything
  the AI is working on). Amber `#E9A23B` is reserved for **source citations** only. Success `#1F9D6B`,
  danger `#D64545`.
- Newsreader (serif) for course content and headlines, Inter for UI, JetBrains Mono for fragment IDs,
  tokens and cost.
- 12 px radii, 8 px grid, thin borders instead of heavy shadows.

## Notes for implementation

- **Model names in mock copy.** Stitch wrote labels such as "Claude 3.7 Sonnet" into some screens.
  Do not copy them: the UI shows the profile's display name from the API (models are configured only in
  `config/ai.php`).
- **Invented metrics.** Some screens show numbers the system does not produce (for example a
  "Confidence 98.4 %" badge on a citation, "Sync hash", a second source file). Citations are either
  resolved or flagged; there is no confidence score in M2.1.
- **Wording.** Stitch occasionally used jargon ("AI-synthesized", "provenance excerpt", "thermodynamic
  efficiency"). The plan's copy pass replaces it with plain language.
- **Images.** No images are hotlinked by the app; any image in `code.html` is a Stitch placeholder.
- Screens are desktop only. The studio must also work at 1024 px (inspector as a drawer) and pass
  WCAG 2.2 AA (keyboard path, focus moved to new surfaces, no colour-only diff states).
