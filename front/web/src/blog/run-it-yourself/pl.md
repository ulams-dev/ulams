Dla mnie open source zaczyna się w momencie, w którym mogę go odpalić u siebie. Bez demo calla 😄

ULAMS ma launcher CLI. Instalujesz go, masz Dockera i:

```bash
ulams stack up
```

- wstaje API, panel, Studio i interfejs uczestnika
- tworzy się pierwsza akademia
- hasła trafiają do pliku, nie na ekran

What's real: lokalny trial używa symulowanych odpowiedzi AI, więc nie płacisz za żadne wywołania modelu. Prawdziwe generowanie wymaga podpięcia dostawcy. Produkcja to dodatkowo domeny, HTTPS i usługi — ale od tego jest osobna instrukcja.
