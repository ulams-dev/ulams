For me, open source starts the moment I can run it myself. No demo call 😄

ULAMS has a CLI launcher. Install it, have Docker, and:

```bash
ulams stack up
```

- API, admin panel, Studio and learner interface come up
- your first academy is created
- passwords go to a file, not to the screen

What's real: the local trial uses simulated AI responses, so you pay for no model calls. Real generation needs a provider configured. Production also needs domains, HTTPS and services — there's a separate guide for that.
